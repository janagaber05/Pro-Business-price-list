نشر على الموقع

Vercel بيعرض ملف products.json من GitHub. عشان الكل يشوف تعديلاتك:

  1. اضغط تحميل products.json بالأسفل.
  2. افتح مستودع GitHub → ارفع الملف مكان القديم (Replace).
  3. استنى دقيقة أو اتنين لحد Vercel يعمل Redeploy.
  4. حدّث صفحة الموقع — التعديلات هتظهر للجميع.

مشاركة قائمة الأسعار

حمّل جدولاً يفتح في إكسل أو Google Sheets لإرساله للعملاء. السعر المعروض هو سعر الكيلو الواحد.
